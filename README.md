# Video Game Sales Data Cleaning

I worked on a video game sales dataset using Python and Pandas.

The main goal of this project was to identify and clean common data quality issues such as:

- Missing values
- Duplicate records
- Incorrect data types
- Inconsistent values
- Invalid values

I also checked columns like User Score, Metacritic Score, Discount, Sales, and Revenue.

### Tools Used
- Python
- Pandas
- Jupyter Notebook
- Excel

After cleaning the data, I saved the final dataset as a separate Excel file for further analysis.
